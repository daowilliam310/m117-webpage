How It Works

  • Shadow DOM: Credentials are collected in a closed Shadow DOM that cannot be accessed from the main document
  • Closure: SessionId is stored in a JavaScript closure, never exposed to global scope
  • Server-Side Validation: All actions are validated on the server against an allowlist
  • Proxy Pattern: Only the execute() method is exposed, never the actual credentials

Example: How Chatbot Would Use This

// Chatbot receives user request: "Send report to john@example.com"

// ✅ ALLOWED: Use proxy to perform action
await window.chatbotAPI.execute('send_email', {
  to: 'john@example.com',
  subject: 'Monthly Report',
  body: 'Here is your report...'
});

// ❌ BLOCKED: Cannot access credentials directly
console.log(window.sessionId);        // undefined
console.log(window.credentials);      // undefined
document.querySelector('input[type=password]').value; // empty/inaccessible
